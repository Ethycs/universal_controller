## When to archive

- A doc's primary-folder copy is being rewritten and the prior version has historical value → archive the old copy, add a row here.
- A design is retired by reality → archive it out of `01 - Design`, add a row here. `01 - Design/02 - UC as a Local Service.md` will come here if the build lands a different shape.
- A raw chat transcript has been decomposed into docs → archive the transcript, point at the docs it produced.

Do **not** archive brainstorm dumps or unresolved TODO stubs. Delete those or keep them out of the tree.
